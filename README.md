> 卖方研究 / 投研人员的网页摘录利器：选中即存、截图留痕、来源可溯，一键导出合规底稿 Excel

写研报做底稿，最烦的就是在网页和 Excel 之间反复复制粘贴：怕原文被删改要截图留证、要逐条手打"来源：xxx 网址：xxx"、攒了一堆素材整理到头大。这个扩展把整条链路自动化：

- **一键摘录**：网页选中文字 → 右键 → 自动截图当前页面并**高亮选中部分**，同时记录来源、网址、时间
- **来源自动识别**：内置规则库覆盖微信公众号、巨潮资讯、交易所、政府网站、主流财经媒体与研报平台；手动修正一次，同域名终身记住
- **PDF 也能摘**：浏览器打开的 PDF（含本地文件）支持框选截图摘录，图表表格轻松留证
- **项目化知识库**：摘录按项目归集（支持多项目），可为每个项目撰写核心观点与大纲，一键导出 Markdown/JSON **直接喂给 AI 生成带引用的报告初稿**
- **导出即底稿**：勾选素材一键导出排版好的 .xlsx——截图嵌入单元格、来源和超链接就位，就是一份规范的研究底稿
- **数据不出本机**：全部存于浏览器本地，无云端、无账号，合规友好；支持一键备份/恢复

**浏览器兼容**：Chrome 88+ / Edge 88+（同一套代码，下文 `chrome://` 替换为 `edge://` 即可）

## 安装

1. 打开浏览器，地址栏输入 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 右上角（Edge 为左侧栏底部）打开「开发者模式」
3. 点「加载已解压的扩展程序」（Edge 为「加载解压缩的扩展」），选择本文件夹（`extension/`）
4. 建议把扩展图标固定到工具栏（拼图图标 → 图钉）
5. 如需摘录**本地 PDF 文件**（file://）：扩展「详情」页打开「允许访问文件网址」开关

## 使用

1. **网页摘录**：任意网页选中文字段落 → 右键 →「加入数据底稿」→ 扩展先自动截图并高亮，随后页面右下角弹出浮层：勾选项目（支持多选，一条摘录可同时属于多个项目；输入新名回车创建）、可顺手填备注 → 回车确认（默认勾选上次项目）；Esc 取消则放弃本次摘录
2. **PDF 摘录**：在 PDF 标签页（浏览器内置阅读器）点击扩展图标 → 自动截取当前画面并打开裁剪页 → 鼠标框选段落/图表 → 填项目/备注（可手工摘抄文字）→ 保存入库。普通网页想截取图表区域，可用右键菜单「区域截图摘录」走同样流程
3. **打开面板**：在普通网页点击工具栏扩展图标（PDF 阅读器等禁注入页面点图标进入的是区域截图流程）
4. **导出**：面板勾选若干条 →「导出选中为 Excel」→ 得到含截图、来源、超链接的 .xlsx
5. **单张图片手工粘贴**：面板里右键点缩略图 →「复制图片」→ 到 Excel 粘贴

## 功能说明

- **来源识别**：内置规则库（微信公众号/巨潮/交易所/政府网/主流财经媒体与研报平台）→ 页面元数据 → 域名兜底；面板上可手动修正来源，修正后同域名自动记忆套用（带「自定义」标签），并会提示是否将同域名旧记录批量统一；「设置」Tab 中可查看/删除已记住的域名映射
- **项目分组**：面板顶部设「当前项目」，新摘录自动归入；可按项目筛选、批量改归属、按项目导出
- **项目知识库（喂给 AI）**：面板「项目知识库」Tab 中按项目填写核心观点与报告大纲（自动保存），一键导出 Markdown / JSON（含全部摘录正文、批注、来源、网址；截图本体留在面板），可直接投喂给 LLM 生成带引用的报告初稿
- **拖拽排序**：卡片顺序即导出行序（筛选状态下不可拖拽）
- **数据存储**：全部存于浏览器本地 IndexedDB，不上传任何服务器

## 数据存储

全部数据存于浏览器本地（IndexedDB + storage），不上传服务器；卸载扩展会删除数据，请定期在「设置」Tab 用「备份全部数据」导出 JSON 备份，换机/重装时用「恢复」导入（支持合并或清空重建两种方式）。

## 已知边界（MVP）

- 截图为当前可视区域，非整页长图
- 批量粘贴图片到 Excel 不可行（剪贴板只带图片引用地址），批量场景请用「导出 Excel」
- `chrome://` 等浏览器内部页面无法截屏；PDF 阅读器无法注入脚本取文字，走「区域截图摘录」模式
